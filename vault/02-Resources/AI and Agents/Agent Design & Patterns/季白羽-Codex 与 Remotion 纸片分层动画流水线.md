# 季白羽-Codex 与 Remotion 纸片分层动画流水线

> 一手 X Article（[@vbjby3](https://x.com/vbjby3/status/2076530524110369070)，2026-07-13，316K 次观看）。作者用一条**本地视频流水线**做出唐朝纸片分层动画，把过程拆成 10 步讲清楚。
>
> 全文一句话主线：**纸片分层动画的关键不是生成一张漂亮的图，而是把画面拆成独立素材层（背景/后排/主体/前景），让每层按不同节奏运动；Codex 不替代绘图/配音/渲染，而是把一堆工具串成流水线的指挥家。**

## 工具链：每个工具只干一件事

这不是一个软件完成的，是一条本地流水线。**Codex 是核心控制台**，其余可替换：

| 工具 | 在流程中的作用 | 是否必需 |
|---|---|---|
| **Codex** | 读取文案、设计分镜、生成项目代码、调整人物位置、执行命令和渲染 | 核心控制台 |
| **Imagegen** | 生成唐朝人物、宫殿、水墨山脉、纸片装饰等图片素材 | 可换其他绘图模型 |
| **Python + Pillow + NumPy** | 批量抠图、检查透明通道、把人物素材表拆成独立 PNG | — |
| **F5-TTS** | 用参考音频做本地零样本声音克隆，生成中文旁白 WAV | 可换真人录音或其他 TTS |
| **Remotion** | 用 React 代码控制图层、人物入场、镜头、字幕、音效并渲染视频 | 核心视频引擎 |
| **FFmpeg / ffprobe** | 检查音视频时长、抽取关键帧、检查分辨率和音轨 | — |
| **Chrome / Remotion Studio** | 浏览器里逐帧预览动画、检查排版 | — |

Codex 把工具串起来的主线：`文案 → 分镜 → 素材清单 → 生成图片 → 抠图拆层 → 编写 Remotion 动画 → 生成配音 → 加字幕音效 → 渲染 MP4`。项目里 Codex 主要改：`src/ReplicaChapterScene.tsx`（人物坐标/大小/层级/动画）、`src/MainVideo.tsx`（配音/背景音乐/音效/字幕）、`src/script.json`（文案/镜头/时长）、`public/assets/`、`public/audio/`。

## 关键方法论（为什么这么做）

1. **先定镜头，再画图。** 同一个人物在全景和特写里的大小、位置、朝向都不同。先随便生成素材，后面很容易出现人物比例错误、视线方向相反、主次不清。这条测试片只用了两个核心镜头：全景（皇帝最大、左右侍女第二、右侧群臣最小，交代"盛唐长安"规模）、特写（中央捧礼盒的人最大、前排跪拜第二、后排侍从最小，表现"万邦来朝"）。
2. **每个镜头至少拆四层。** 背景层（山水/宫殿/城楼/纸纹，最慢，只轻微漂移推镜）、后排层（远处群臣/侍从/建筑边角，移动小、透明度稍低）、主体层（皇帝/捧礼盒的人，尺寸最大、入场最有力量）、前景层（侍女/跪拜人物/纸屑/胶带，移动稍快，用来遮挡并制造纵深）。
3. **人物必须是独立 PNG，不能画在同一张图里。** 人物一旦和背景粘在一起，后面就不能独立飞入、摇摆或调整大小。
4. **背景底板不含主要人物。** 只保留环境（红色宣纸底纹/水墨山脉/宫殿城楼/撕纸边缘/网点胶带印章）。本片用两张底板：全景偏米白（突出金色皇帝）、特写大面积深红（突出中央礼盒人物）。
5. **按叙事重要性安排大小，不是平均分布。** 全景：皇帝宽 650、左右侍女 235～245、右侧群臣 158～170；特写：中央礼盒人物宽 575、前排跪拜 285～330、后排侍从 165～180。
6. **纵深靠遮挡关系，不是 3D。** 正确层级顺序：背景底板 → 后排 → 中排 → 前排 → 字幕装饰。每个图层独立 zIndex（中央礼盒人物 z:5、前排跪拜 3～4、后排侍从 1～2）。再叠统一白色纸片描边（剪纸感）+ 深色阴影（把人物从背景抬起来）：

   ```
   filter: drop-shadow(4px 0 #f5eedc) drop-shadow(-4px 0 #f5eedc)
           drop-shadow(0 4px #f5eedc) drop-shadow(0 18px 9px rgba(20,15,12,.32))
   ```

## Remotion 动画：按角色分参数 + 错峰入场

人物分三种角色，配不同动画参数（`startScale` 越小，入场缩放越明显）：

```
primary:   { distance, rise, startScale: 0.86 }   主角移动最大，轻微缩放+落地感
secondary: { distance, rise, startScale: 0.90 }   从左右两侧进入，幅度中等
tertiary:  { distance, rise, startScale: 0.95 }   后排只小幅移动，避免抢戏
```

- 背景只做约 **1% 慢速推镜**。
- 所有人物入场后保留**极轻微上下漂浮**，避免画面完全静止。
- **人物不同时出现**——用 delay 错开：主角先出现 → 配角补充 → 群像完成，而不是一下子塞满。

## 抠图与配音

- **抠图**：Imagegen 生成角色时提示词必须同时限制——唐代服饰发冠、古籍线描+手工拼贴质感、明确朝向、完整人物不裁手脚、白色剪纸描边、纯色背景（方便抠图）、不要文字水印复杂场景。生成纯绿色背景 → 本地脚本转透明 PNG → 素材表拆成多个独立 PNG（`python scripts/split_sheet.py <source> <layers> <prefix>`）。
- **F5-TTS 声音克隆**：需要一段参考音频 + 对应文字，再生成新旁白：

  ```json
  { "ref_file": "参考音频.wav",
    "ref_text": "参考音频对应的文字",
    "full_text": "需要合成的唐朝口播文案",
    "full_out": "public/audio/tang-wide.wav" }
  ```

  参考音频必须干净、单人说话、没有音乐。生成后用 FFmpeg 调到目标语速。

## 音频四层（配音决定镜头时长）

画面完成后，按配音长度切镜头。音频分四层：旁白（每段单独一个 WAV，直接决定镜头时长）、背景音乐（循环，音量保持人声下方）、章节音效（切镜头时 impact 或 riser）、人物入场音效（主角 impact / 次要 whoosh / 后排 tick 或 pops）。字幕只留一层、固定底部、逐句跟随旁白。

## 验收：Remotion Studio 预览 + FFmpeg 抽帧

预览重点查：人物头手脚有没有被裁、朝向是否符合场景、主角配角大小有没有拉开、前后排有没有错误遮挡、人物有没有同时出现、字幕是否挡住脚部/关键道具、音效是否和入场帧对齐。最后 `ffprobe` 查分辨率/时长/音轨、`ffmpeg -ss` 抽帧检查排版，`npm run render` 渲染 MP4。

## 限制与可迁移

- Imagegen 可换任何绘图模型；F5-TTS 可换真人录音或其他 TTS。**真正不可替换的是 Codex（指挥）和 Remotion（引擎）**。
- 这套方法不只适合唐朝题材——历史人物、知识科普、商业故事、人物关系、城市发展，**只要画面能拆成"背景、主角、配角、前景"，都能复用同一流程**。
- 边界判断（作者原话）：真正让纸片动画有层次的，不是多生成几张图片，而是**让每一张图片都承担明确的叙事位置**。
