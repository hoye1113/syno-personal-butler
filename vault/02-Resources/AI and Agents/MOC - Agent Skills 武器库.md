# MOC - Agent Skills 武器库

> **理论基石**：参见 [[从过度规训到大松绑——强模型时代的 Agent Skills 演进与重构]]。  
> **核心原则**：摒弃繁文缛节与保姆式过度规训，坚持**“姿态胜于步骤、代码硬契约胜于八股、感官镜子胜于手把手”**。以下严选收录的 22 大原子技能卡片，构成了管家在实战攻坚、认知进化与美好生活中的 S 级核心武器库。

---
