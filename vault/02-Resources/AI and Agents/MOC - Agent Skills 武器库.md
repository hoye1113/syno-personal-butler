# MOC - Agent Skills 武器库

> **理论基石**：参见 [[从过度规训到大松绑——强模型时代的 Agent Skills 演进与重构]]。  
> **核心原则**：摒弃繁文缛节与保姆式过度规训，坚持**“姿态胜于步骤、负向红线胜于八股、感官镜子胜于手把手”**。以下精选收录的 9 大原子技能卡片，构成了管家在实战攻坚与美好生活中的核心武器库。

## 一、武器库全景矩阵与路由表

| 维度 | 技能名称 | 核心定位与产出 | 推荐调用场景 | 对应原子卡片 |
|---|---|---|---|---|
| **工程心智** | **ponytail** | 最懒资深架构师，能不写代码就不写，专注减法审计 | 方案设计初审、代码排错、反过度工程化 | [[ponytail - 最懒资深架构师心智|ponytail]] |
| **工程心智** | **archify** | 交互式动态架构图生成器，支持折叠、链路高亮与单文件 HTML | 复杂代码库全景梳理、系统重构、技术设计方案 | [[archify - 交互式动态架构图生成器|archify]] |
| **工程心智** | **reality-check** | 代码诚实度无情审计，专查假测试、Mock 滥用与假健康检查 | 代码合并前审查、发布前体检、外部依赖审查 | [[reality-check - 代码诚实度无情审计|reality-check]] |
| **视觉设计** | **open-design** | 本地优先开源设计引擎，一键交付落地页、交互原型与 PPT | 独立项目原型快速验证、商业幻灯片与视频输出 | [[open-design - 本地优先全能设计引擎|open-design]] |
| **认知科普** | **concept-fable** | ≤1000字 零术语抽象概念寓言，附带概念解剖与迁移检验 | 快速消化硬核论文、向非技术人员生动科普 | [[concept-fable - 零术语抽象概念寓言|concept-fable]] |
| **研究情报** | **geo-content-optimizer** | 生成式引擎引用优化（GEO），为 AI 搜索打造权威事实源 | 知识库深度文章对外发布、技术博客与产品文档 | [[geo-content-optimizer - 生成式引擎引用优化|geo-content-optimizer]] |
| **严谨数据** | **huashu-excel** | 脏表体检、口径定义、双向勾稽对账与审计级报告 | 个人财务账单梳理、投资收益对账、业务数据分析 | [[huashu-excel - 数据全流程与严格对账|huashu-excel]] |
| **生活手帐** | **travel-memory-sticker-card** | 手机随手拍照片 → 3:2 横版水粉剪纸艺术卡 + 6 枚手帐贴纸 | 旅行归来纪念套卡制作、朋友圈与博客高审美配图 | [[travel-memory-sticker-card - 水粉剪纸旅行贴纸卡|travel-memory-sticker-card]] |
| **家庭温情** | **kid-papercraft** | 儿童折纸定格动画短片，三段式温暖剧情与纸艺提示词 | 家庭成员生日祝福、孩子成长纪念日短片、睡前故事 | [[kid-papercraft - 儿童折纸定格动画短片|kid-papercraft]] |
