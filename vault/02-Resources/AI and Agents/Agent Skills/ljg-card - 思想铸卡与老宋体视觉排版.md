# ljg-card — 思想铸卡与老宋体视觉排版

> **核心哲学**：*“内容进去，PNG 出来。生成图负责把思想变成可见动作，HTML 负责把话说准确。拒绝花哨彩底与压抑行距，以纯正的京华老宋体与大面积素净留白，铸造具有中国古典文人风骨的当代数字卡片。”*

---

## 一、What：它能做什么

`ljg-card`（代号：**铸 / Content Caster**）是全网广泛流传的李继刚卡片排版核心。它彻底跳过了市面上千篇一律的卡片模板，利用**无头 HTML 精确排版 + 纯正中国字体渲染**，提供 4 大专属工业模具：

1. **`-l`（默认：长图 · 静线叙事）**：
   - 尺寸：1080 × auto；
   - 结构：顶部一个安静的主场景视觉（把抽象判断具象化为一个物理动作），正文克制展开，必要时追加至多 2 个连续视觉拍点；
2. **`-f`（全文 · 原文排版）**：
   - 尺寸：1080 × auto；
   - 纯正的文人长文阅读面：固定为纯白 `#FFFFFF` 画布，正文使用深中性黑 `#171717`，辅助信息用中性灰；
   - **零图像生成**：不瞎生成插图，只严格保真呈现原稿自带的图表，不压缩字号，允许长图自由生长；
3. **`-c`（漫画分镜）**：
   - 缺口驱动、同一案情重跑的多格漫画分镜叙事；
4. **`-w`（白板 · 纵向论证）**：
   - 嵌入承重推理节点的局部手绘黑白动作，不设顶部主视觉，专注于核心论证链条的可视化。

---

## 二、Why：为什么强模型时代必收此技能

### 1. 痛点：AI 出图与卡片生成的“审美灾难”
许多所谓“AI 知识卡片生成器”存在三大致命伤：
- **花哨过载**：到处是刺眼的渐变色、无意义的 3D 拟物图标和杂乱 emoji，完全淹没了文字；
- **字体丑陋**：默认使用冰冷的系统黑体，缺乏东方文字的笔锋、顿挫与典雅感；
- **排版拥挤**：为了把内容硬塞进一张固定尺寸的图里，拼命缩小字号、压缩行距，造成极大的阅读窒息感。

### 2. 现代 Harness 范式：设计规范代码化与严格字体优先级
`ljg-card` 建立了近乎苛刻的排版工程契约：
- **字体优先级铁律**：首选已安装的 `KingHwa_OldSong`（京华老宋体），依次回退到 `Songti SC` / `STSong` / `Noto Serif CJK SC`。标题用宋体立风骨，代码用等宽字体保留语义；
- **呼吸感行高**：1080px 宽度下，正文不小于 40px，行高死守 1.9，段距 36px，正文有效宽度锁定约 896px，手机端阅读毫无压力；
- **隔离工作区**：强制在临时目录组装 HTML/CSS/矢量/生成图，QA 校验后才输出干净的最终 PNG。

---

## 三、How：核心指令与调用规约

### 1. 命令行调用模式

```bash
# 默认长图模式：提炼核心观点，带 1 个安静叙事主场景
ljg-card "输入长文或 URL" -l

# 全文保真排版模式：不改动文字，不生成新图，老宋体纯净长卡片
ljg-card article.md -f

# 逻辑白板论证模式：只在关键承重推演节点嵌入板书图解
ljg-card thesis.md -w
```

### 2. 视觉母题映射流水线（仅 `-l` / `-c` / `-w`）

```
[原始文本输入]
       ↓
[提炼核心判断] -> 识别核心冲突与张力
       ↓
[建立视觉母题表] -> 判断 → 冲突 → 视觉动词 → 承载物 → 安全区
       ↓
[HTML/CSS 组版] -> 注入 KingHwa_OldSong 字体与 1.9 呼吸感行高
       ↓
[Playwright 渲染] -> 生成 1080 宽无损高清长图 PNG
```

## 四、管家系统落地与实战转化建议

1. **知识库金句与重点文章出图**：
   - 当主人在知识库看到一篇绝妙长文，需要分享到朋友圈、即刻或小红书时，唤醒 `ljg-card -f`，秒级输出典雅的老宋体全景长图；
2. **配合 concept-fable 形成图文双绝**：
   - 用 `concept-fable` 创作零术语抽象概念寓言，用 `ljg-card -l` 铸造为一张具有东方哲思的静态视觉艺术卡。
