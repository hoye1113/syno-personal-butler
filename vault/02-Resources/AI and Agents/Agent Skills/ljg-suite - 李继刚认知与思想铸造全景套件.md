# ljg-suite — 李继刚认知与思想铸造全景套件

> **核心哲学**：*“AI 时代最稀缺的不是信息处理速度，而是人类独特的直觉与母语的骨骼感。不写没有血肉的翻译腔，用汪曾祺、阿城、王小波的笔调重塑中文；不搞死板的逻辑罗列，用物理直觉与意象公式击穿本质；内容进去，高审美卡片出来——这就是思想铸造。”*

## 二、Why：为什么强模型时代必收此套件

### 1. 痛点：通用 AI 的“平庸化、翻译腔与审美荒漠”
无论底层基座是 GPT-6.1 还是 Claude 5.5，通用模型在面对中文内容时天然倾向于：
- 充斥着“不可否认的是”、“值得注意的是”、“具有里程碑意义”等假大空的公关辞令；
- 视觉排版粗糙丑陋，毫无字型呼应与留白节奏；
- 思考问题流于表面罗列，无法穿透至第一性原理。

### 2. 现代 Harness 范式：母语质感与物理意象
李继刚体系证明了**高级 Prompt 本质上是认知哲学的重塑**：
- **汪曾祺/阿城文风约束**：强制模型使用短句、动词、具象名词，赋予文字呼吸感与重量；
- **数学与物理隐喻**：用“特征值降秩”、“追本之箭”、“热力学第二定律与熵减”来分析一切事物，跳过表层伪因果；
- **排版即态度**：以老宋体（`KingHwa_OldSong`）和纯白/深黑对比，建立无可替代的高审美视觉护城河。

## 三、How：四大核心拳头技能索引

本套件中，最具代表性、已被提炼为原子卡片的四大核心拳头工具：

1. **[[ljg-card - 思想铸卡与老宋体视觉排版]]**：内容进去，PNG 出来。4 大模具（长图、全文、漫画、白板）+ 京华老宋体排版。
2. **[[ljg-think-rank - 追本之箭与认知降秩生成器]]**：垂直深钻到不可再分本质 + 砍掉所有表面现象提取 2~3 个核心自由度。
3. **[[ljg-writes - 汪曾祺与阿城笔调纯正中文写作引擎]]**：五刀三磨工序，彻底清除 AI 塑料油腻味，写出带泥土香气的纯正中文。
4. **[[ljg-invest - 秩序创造机器与创生公式投资法]]**：打破传统财报估值，核心灵魂拷问——“该项目到底是不是一台秩序创造机器？”。

## 四、全套 15 技能速查表

| 技能代号 | 中文名称 | 核心触发词 | 一句话精髓 |
|---|---|---|---|
| `ljg-card` | **铸** | `铸`, `做成卡片` | 视觉排版巅峰，HTML保真，生成图表达动作 |
| `ljg-present` | **演讲铸造器** | `做演讲`, `slides` | Unix气质单文件HTML，巨句、对照、Unicode图 |
| `ljg-think` | **追本之箭** | `想透`, `追本` | 纵向深钻，像箭一样刺入不可再分的本质 |
| `ljg-rank` | **降秩** | `降秩`, `找秩` | 砍掉表面现象，找出背后真正撑着的几根独立的力 |
| `ljg-structure` | **结构风洞** | `找结构`, `母题` | 发现母题级别生成机制，用逻辑风洞检验因果 |
| `ljg-constraint`| **约束映射** | `找约束`, `边界` | 区分物理硬约束与人类自设假约束，绘制解空间 |
| `ljg-writes` | **写作引擎** | `写作引擎`, `五刀` | 汪曾祺/阿城笔调，1000~1500字逻辑递进与反例打磨 |
| `ljg-plain` | **认知原子·白** | `白话说`, `说人话` | 形式随内容，聪明的 12 岁少年也能瞬间秒懂 |
| `ljg-word` | **词源破译** | `解词`, `单词拆解` | 物理画面 + 意象公式 + 一语道破哲学金句 |
| `ljg-is` | **概念重塑** | `X是什么`, `意味着什么` | 讲清是什么、与相邻概念差异、运作机制与行动抓手 |
| `ljg-learn` | **八维概念解剖** | `概念解剖`, `8维` | 历史/辩证/现象/语言/形式/存在/美学/元哲学切开 |
| `ljg-teach` | **情境教学** | `用情境教我` | 体验先行，公平意外显化认知缺口，撞墙后再命名 |
| `ljg-invest` | **秩序机器** | `投资分析`, `秩序` | 不看财报粉饰，只查是不是一台「秩序创造机器」 |
| `ljg-book` | **拆书系统** | `拆书`, `走两步` | 提炼 5 件事 + 绘制认知地图 + 给出可落地的走两步 |
| `ljg-roundtable`| **智囊圆桌** | `圆桌讨论` | 张力网络选人，思想家碰撞对冲，逼出共识边界 |
