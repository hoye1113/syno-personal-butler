# ljg-invest — 秩序创造机器与创生公式投资法

> **核心哲学**：*“热力学第二定律告诉我们，宇宙万物天然滑向混乱与熵增。一个商业组织能活下来并创造超额价值，唯一的理由是：它在局部对抗熵增。不要被创始人巧舌如簧的商业计划书（BP）迷惑，更不要被短期修饰的财报蒙蔽——核心灵魂拷问只有一个：这个项目，到底是不是一台‘秩序创造机器’？”*

---

## 一、What：它能做什么

`ljg-invest` 是李继刚开创的**物理主义与耗散结构商业投资评估模型**。它彻底打破了传统金融学只看三张财务报表、PE 倍数或行业规模的局限，而是从更深层次的热力学与系统论视角审视创业项目：

1. **核心灵魂判定：秩序创造机器（Order-Creating Machine）**：
   - 输入的是混乱、无序、高交易成本与弥散的信息；
   - 输出的是高度确定、低摩擦、可复制的秩序与信用；
   - 评估该机器在运转过程中，是“消耗自身热量维持表面繁荣（伪秩序）”，还是“利用外部能量流自发形成负熵流（耗散结构）”；
2. **商业创生公式（Genesis Equation）**：
   - 拆解项目的底层能量转换逻辑：
     $$\text{商业价值} = \frac{\text{所消减的混乱度} \times \text{所节约的系统交易成本}}{\text{维持该组织自身运转所需的摩擦成本}}$$
3. **穿透创始人真实心智**：
   - 深入分析与创始人的真实对话记录与决策历史；
   - 辨别创始人是在“靠套利收割暂时的制度缝隙”，还是在“物理层面真实降低了社会的能量消耗”。

---

## 二、Why：为什么强模型时代必收此技能

### 1. 痛点：传统投资分析的“滞后性与容易被粉饰”
现代大模型被灌输了大量华尔街或券商的投资模型，但这些模型在面对早期项目或新技术范式（如 AI Agent 原生企业、开源协议）时常常失灵：
- 早期项目没有亮眼的利润表，传统 DCF 折现模型直接失效；
- 创始人可以用各种流行概念（如 Web3、AGI、低代码、出海）包装 BP，模型容易陷入其叙事陷阱。

### 2. 现代 Harness 范式：基于物理守恒与熵减的第一性度量
`ljg-invest` 提供了一把不可被欺骗的**物理学试金石**：
- 如果一个项目的商业模式本质上只是“把无序从左口袋倒到右口袋”，它迟早被热力学规律碾碎；
- 唯有在局部创造了实质性负熵、降低了整体社会摩擦成本的项目，才具备跨越周期的硬核生存力。

## 三、How：核心评估协议与报告维度

### 1. 秩序创造机器四层透视协议

```
[创始人输入 / 项目商业计划书 (BP)]
                   ↓
1. 【混乱源头定位】: 它面对的原初混乱是什么？ (信息不对称 / 流程冗长 / 算力浪费)
                   ↓
2. 【负熵转换机制】: 它的核心引擎是什么？ (是靠堆人力补贴，还是靠算法/协议自运转？)
                   ↓
3. 【自毁倾向排查】: 随着规模扩张，组织自身产生的内耗（组织熵）是否会反噬创造的秩序？
                   ↓
4. 【创生公式闭环】: 是否具备正向现金流造血的物理必然性？
                   ↓
[产出: 秩序创造定级与终局推演报告]
```

### 2. 核心判定标准表

| 判定等级 | 物理特征 | 投资结论 |
|---|---|---|
| **S 级：天然负熵泵** | 随用户增多，系统整体混乱度指数级下降，自发聚集能量（如 Linux、TCP/IP、微信） | **全力下注**，具备无限生命力 |
| **A 级：高能效发动机** | 组织效率极高，每消耗 1 焦耳能量可消除外界 10 焦耳混乱（如高通专利、台积电先进制程） | **合理估值买入** |
| **B 级：摩擦力套利者** | 依靠牌照、信息差或短期补贴生存，不创造新秩序 | **短期谨慎波段**，警惕缝隙被抹平 |
| **C 级：高熵碎纸机** | 组织膨胀速度远超创造价值速度，本质是资本供暖下的假象（如诸多伪需求 O2O/元宇宙） | **绝对回避**，热力学必然死亡 |
