# financial-report-reader — 财报三表联动与暴雷排查

> **核心哲学**：*“利润表是愿望，资产负债表是现状，现金流量表才是真实真相。不要让大模型在财务数据里猜算术；把会计勾稽关系和排雷阈值写成硬核 Python 脚本，让 AI 在确定性异常检测的基础上撰写高质量商业洞察。”*

---

## 一、What：它能做什么

`financial-report-reader` 是一个结合**确定性数据脚本 + 深度商业推理**的财报三表结构化解读工具。它通过读取标准化的财务 JSON 数据，提供以下核心能力：

1. **三表联动全景计算**：
   - 利润表（收入、成本、营业利润、净利润）；
   - 资产负债表（应收账款、存货、流动资产、商誉、应付账款、资产负债率）；
   - 现金流量表（经营性现金流 OCF、投资现金流、筹资现金流、资本开支 CapEx）；
2. **多周期动态趋势分析**：
   - 同比（YoY）：识别跨年度结构性景气度与成长拐点；
   - 环比（QoQ）：捕捉相邻季度的短期边际波动与季节性异动；
3. **10 项硬核财务异常自动扫描（排雷引擎）**：
   - **应收账款暴增**：应收账款增速显著超前于营业收入增速（疑似塞货或放宽信用赊销）；
   - **现金流与净利润背离**：净利润光鲜亮丽，但经营现金流骤降甚至为负（典型的“纸面富贵”）；
   - **存货异常积压**：存货增速远超营收与营业成本（滞销或滞后计提减值）；
   - **毛利率剧烈突变**：在无技术突破背景下毛利率异常跳涨（疑似成本跨期操纵）；
   - **债务天花板警报**：资产负债率触及警戒线（默认 70%）或流动比率跌破安全底线（< 1.0）；
   - **商誉虚高吞噬风险**：商誉占总资产比重超标（默认 > 30%，潜在巨额暴雷减值风险）。

## 二、Why：为什么强模型时代必收此技能

### 1. 痛点：纯 LLM 解读财报的“算术幻觉与盲目乐观”
通用大模型在面对复杂的财务多期报表时，极其容易出现两大致命缺陷：
- **算术计算不可靠**：计算同比、环比、周转率和勾稽差额时频繁出现计算幻觉；
- **缺乏审慎怀疑姿态**：模型习惯于顺着公司财报公关稿的逻辑，夸奖“净利润同比增长 30%”，却完全察觉不到“经营现金流为负数、应收账款翻倍、商誉占一半”的致命暴雷前兆。

### 2. 现代 Harness 范式：确定性脚本做底座，大模型负责定性推理
本技能践行了极佳的架构分工：
- **底层（Deterministic CLI）**：使用 `analyze_financials.py` 纯 Python 脚本，以毫秒级速度执行 100% 精确的会计勾稽计算与 10 项规则阈值判定；
- **上层（Cognitive Layer）**：模型拿到结构化的异常警告（Warnings）与指标后，结合行业背景、宏观周期和商业模式，撰写有深度、有骨气的定性分析。

## 三、How：核心 CLI 接口与数据契约

### 1. 快速使用指令

```bash
# 基本用法：分析财务 JSON 数据，输出可读终端报告
python scripts/analyze_financials.py data.json

# 导出排雷报告为结构化 JSON
python scripts/analyze_financials.py data.json --output report.json

# 调整自定义排雷阈值（例如更严苛的应收暴增警戒线）
python scripts/analyze_financials.py data.json --ar-threshold 0.15 --ocf-ratio 0.6
```

### 2. 核心排雷阈值参数表

| 参数名 | 默认值 | 触发条件说明 | 风险含义 |
|---|---|---|---|
| `--ar-threshold` | 0.20 | 应收账款增速 - 营收增速 > 20% | 渠道塞货、放宽账期假增收 |
| `--inv-threshold` | 0.15 | 存货增速 - 营收增速 > 15% | 货物滞销、存货减值风险 |
| `--ocf-ratio` | 0.50 | 经营现金流 / 净利润 < 0.50 | 纸面利润、回款恶化、造假嫌疑 |
| `--margin-threshold` | 0.05 | 环比毛利率跳变 > 5% | 成本归集异常、跨期平滑利润 |
| `--debt-ceiling` | 0.70 | 资产负债率 > 70% | 财务杠杆过高、偿债危机 |
| `--current-floor` | 1.00 | 流动比率 < 1.00 | 短期偿债缺口、流动性紧张 |
| `--goodwill-ceiling` | 0.30 | 商誉 / 总资产 > 30% | 资产虚胖、商誉减值引信 |

## 四、管家系统落地与实战转化建议

1. **用于主人投资与竞品研究**：
   - 结合前线信息抓取工具，将上市公司的公开季报/年报提取为标准三表 JSON；
   - 由 Syno 后台自动化调用脚本进行秒级排雷，在控制台高亮标记“潜在财务地雷”；
2. **配合价值投资卡片协同作战**：
   - 排雷通过后，再交由商业估值模型评估竞争护城河与安全边际，形成闭环。
