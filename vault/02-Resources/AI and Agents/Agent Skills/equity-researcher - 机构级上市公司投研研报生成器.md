# equity-researcher — 机构级上市公司投研研报生成器

> **核心哲学**：*“业余投资者看情绪和消息面，顶级投研机构看商业本质、产业链博弈与现金流折现。不要满足于泛泛而谈的‘未来前景广阔’；用投行级的严肃框架，搭建财务模型、进行情景推演与敏感性压力测试，让每一笔投资都有据可依。”*

---

## 一、What：它能做什么

`equity-researcher` 是一个面向**二级市场专业投资与商业尽调**的机构级投研研报生成技能。它覆盖中国 A 股、港股和美股上市公司，提供两种经过严格工程验证的交付规格：

1. **模式一：投资速览（Tear Sheet / 3~5 页）**：
   - 快速决策型简报，包含公司业务概览、核心财务指标、估值倍数（PE/PB/PS/EV-EBITDA）；
   - 提炼核心投资逻辑（Catalysts）、护城河定性分析与下行风险提示（Downside Risks）；
2. **模式二：机构深度研报（Equity Report / ≥25 页）**：
   - **宏观与行业格局**：行业生命周期、市场集中度 CR5、竞争格局与五力模型；
   - **产业链解构与供应链图谱**：上游供应商话语权、下游客户黏性、替代品威胁；
   - **三表联动财务预测**：未来 3~5 年营收、净利、资本支出与营运资金预测；
   - **硬核估值模型（DCF Model）**：加权平均资本成本（WACC）、终值计算、无杠杆自由现金流折现；
   - **情景分析与敏感性测试**：乐观/中性/悲观假设推演，WACC 与永续增长率双向敏感性矩阵。

---

## 二、Why：为什么强模型时代必收此技能

### 1. 痛点：通用 AI 做投资分析的“假大空与缺乏量化”
普通大模型在回答“你怎么看某某公司股票”时，通常只会产出千篇一律的废话：“该公司行业地位领先、但也面临竞争加剧风险，建议谨慎评估”。
- 没有具体估值区间；
- 没有现金流折现（DCF）数学计算；
- 缺乏对业务敏感性因素（如原材料涨价 10% 对净利吞噬幅度）的定量测算。

### 2. 现代 Harness 范式：意图路由（Router）与分级交付
本技能在入口处设定了严格的**意图分流门禁（Phase 0 Router）**：
- **Tier A（明确研报关键词）**：直接启动报告生成流程；
- **Tier B（模糊意图，如“看看特斯拉”）**：主动澄清用户需要“3页速览”还是“25页深度研报”，绝不浪费 token；
- **Tier C（简单概念问询）**：直接对话回答，严禁触发重度研报生成。

## 三、How：核心执行流程与分析矩阵

### 1. 投研执行流水线

```
[Phase 0: 路由与模式对齐] -> 锁定目标标的 + 确定 Tear Sheet 或 Full Report
        ↓
[Phase 1: 基础数据与公告采集] -> 官方财报 + SEC/交易所公告 + 行业研究报告
        ↓
[Phase 2: 业务模式与产业链解构] -> 收入拆解 + 单位经济学 (Unit Economics)
        ↓
[Phase 3: 财务建模与预测] -> 历史三表归集 + 未来 3-5 年预测表
        ↓
[Phase 4: 估值与敏感性测试] -> DCF 折现模型 + 可比公司倍数 + 敏感性网格
        ↓
[Phase 5: 研报成稿与交付] -> 生成专业排版 PDF / 结构化 Markdown
```

### 2. 估值与敏感性分析规范示例

```text
+---------------------+---------------------------------------------------+
| 估值方法            | 估值结果 (每股价格) / 相对当前溢价                |
+---------------------+---------------------------------------------------+
| DCF 模型 (基准情形)  | $185.50 (较当前股价 +24.3%)                       |
| P/E 相对估值 (25x)  | $178.00 (较当前股价 +19.3%)                       |
| EV/EBITDA (18x)     | $182.20 (较当前股价 +22.1%)                       |
+---------------------+---------------------------------------------------+
| 综合目标价 (Target) | $182.00 (买入评级 / 安全边际 18%)                 |
+---------------------+---------------------------------------------------+
```

## 四、管家系统落地与实战转化建议

1. **用于主人个人股票与行业研究**：
   - 与前序收录的 `financial-report-reader`（三表排雷）形成无缝配合：先用脚本排雷，排除暴雷公司；再用 `equity-researcher` 搭建估值模型和投资逻辑；
2. **多维表格资产库联动**：
   - 研报的核心结论（目标价、买入区间、关键风险）自动同步至飞书多维表格的“投资观察池”表格，定期跟踪业绩兑现情况。
