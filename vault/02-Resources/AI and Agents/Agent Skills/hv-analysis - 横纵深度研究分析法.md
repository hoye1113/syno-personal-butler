# hv-analysis — 横纵深度研究分析法

> **核心哲学**：*“单看当下，容易把暂时的窗口红利误判为永恒的壁垒；单看历史，又容易深陷过时的路径依赖。唯有在纵向时间轴上追踪每一次不可逆的‘路径锁定’，在横向空间截面上进行全景竞争排布，两条轴交织的十字星处，才是唯一的真实洞察。”*

---

## 一、What：它能做什么

`hv-analysis`（Horizontal-Vertical Analysis）是由知名 AI 创作者「数字生命卡兹克」提出的一套系统性商业与技术研究范式。它将语言学家索绪尔的**历时分析（Diachronic）**与**共时分析（Synchronic）**、社会科学纵向/横截面设计以及商学院案例研究法融为一体：

1. **纵向分析（Longitudinal / Diachronic 轴）**：
   - 沿时间线还原研究对象从诞生至今的完整叙事；
   - 挖掘创始人原生动力、技术原点与关键转折期；
   - 还原关键节点决策：“为什么选了 A 放弃了 B？”、“哪些早期决策锁死了后来的发展方向？”；
   - 划分发展阶段，识别每个阶段的核心特征与主要矛盾；
2. **横向分析（Cross-sectional / Synchronic 轴）**：
   - 在当下的时间切片上，构建全行业竞品矩阵；
   - 从产品形态、商业模式、技术架构、护城河与用户口碑进行横向对照；
3. **十字交汇洞察（Cross-Synthesis）**：
   - 交叉推导核心判断：为什么是它跑赢了（或为什么它面临瓶颈）；
   - 揭示行业演进底层规律；
4. **出版级产物交付**：
   - 配合 WeasyPrint 自动化渲染，生成排版精美、带图表与脚注的出版级 PDF 研究报告。

## 二、Why：为什么强模型时代必收此技能

### 1. 痛点：通用 Deep Research 的“平铺直叙与流水账”
许多大模型在做深度研究（Deep Research）时，通常只是把网上搜到的几十条新闻拼凑成一篇冗长的信息汇总：没有叙事张力，没有因果链条，缺乏对“关键历史抉择”的哲学反思。

### 2. 现代 Harness 范式：多子 Agent 并行搜索与双轴心智架构
`hv-analysis` 通过严格的双轴心智，将复杂研究拆分为清晰的搜索与思考策略：
- **子 Agent 1 负责纵向线索**：创始人背景、版本迭代、战略转向、生死危机；
- **子 Agent 2 负责横向竞品**：市场份额、竞品对比、社群口碑（Reddit / X / V2EX / 知乎）；
- **学术必须查一手论文**：如果涉及前沿模型或算法，强制通过 arXiv API 检索原始论文，绝不依赖媒体二次解读。

## 三、How：核心执行流程与阶段标准

### 1. 四步深度研究流水线

```
[明确研究对象与动机]
         ↓
[Step 1: 多子 Agent 并行一手信息采集]
   ├─ 子 Agent 1: 纵向历时追踪 (博客/Release Notes/SEC文件)
   ├─ 子 Agent 2: 横向共时竞品 (市场矩阵/社群真实验收)
   └─ 子 Agent 3: 学术/论文深挖 (arXiv API / 算法原语)
         ↓
[Step 2: 纵向深度叙事构建] -> 起源追溯 + 演进历程 + 决策锁定 + 阶段划分
         ↓
[Step 3: 横向全景矩阵对比] -> 核心对手 + 多维雷达 + 优劣势解构
         ↓
[Step 4: 十字交汇与洞察提炼] -> 产出核心论断 + WeasyPrint 生成精美 PDF
```

### 2. 负向红线与信息自检

- ❌ **严禁仅凭单一信源下结论**：关键事实必须交叉验证，避免媒体循环印证假象；
- ❌ **严禁写成干燥的清单罗列**：纵向分析必须是一篇引人入胜的叙事故事，展现决策背后的现实无奈与博弈；
- ❌ **严禁泛化竞品评价**：横向对比必须给出硬性指标和真实用户吐槽，不打马虎眼；
- ✅ **一手来源绝对优先**：官方博客 > 创始人推文 > 权威一线报道 > 二次聚合转载。
