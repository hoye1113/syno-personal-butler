# ljg-think-rank — 追本之箭与认知降秩生成器

> **核心哲学**：*“面对复杂，初学者做加法，罗列几十个变量；真正的智者做减法与深钻——像一支无坚不摧的追本之箭，刺穿虚妄的表象，一路垂直下潜到第一性原理；横向则施行‘降秩’手术，把十几个纷繁现象砍到不可再少的两三个生成器。砍完之后，如果不能把现象一个个生回来，就不算数！”*

---

## 一、What：它能做什么

`ljg-think-rank` 是将李继刚认知体系中最为犀利的**追本之箭（ljg-think）**与**降秩算法（ljg-rank）**合二为一的本质透视工具：

1. **纵向武器：追本之箭（The Arrow of Root-Seeking）**：
   - 面对任何观点、商业现象或技术争端，严禁横向发散；
   - 像箭一样垂直向下钻：现象层 → 机制层 → 动机与博弈层 → 物理与人性约束层；
   - 一直下坠至**“不可再分的本质公理”**，终结无效的同义反复；
2. **横向武器：领域降秩（Domain Rank-Reduction）**：
   - 将线性代数中“矩阵降秩与特征分解”的数学哲学迁移到现实世界；
   - 面对一个复杂的商业赛道或社会现象，识别背后真正支撑它的“几根独立的力（Independent Forces）”；
   - **闭环检验铁律**：砍到不可再少还不是终点，必须证明**“仅凭这几根核心生成力，能将所有复杂现象逐一生长出来”**，才算降秩成功。

---

## 二、Why：为什么强模型时代必收此技能

### 1. 痛点：大模型思考的“平面化清单癖”
当让一个顶尖模型“分析某某问题的原因”时，大模型最典型的病态反应是：
- 吐出一份列有 12 个维度的清单（技术、市场、政策、团队、文化、资金...）；
- 表面看起来面面俱到，实际上各个维度彼此重叠、因果倒置、缺乏重心；
- 没有人能从一份 12 点的清单中做出坚定的战略决策。

### 2. 现代 Harness 范式：强制约束自由度（Degrees of Freedom）
`ljg-think-rank` 强制模型在深度与秩维度上进行自我约束：
- 深度上：追本溯源，直到触碰物理定律或生物学本能；
- 广度上：剥离冗余信息，将维数（Rank）压缩至极小。这种“高压紧缩”极大地激发了强模型的深层推理潜能。

## 三、How：核心心智模具与推演协议

### 1. 追本之箭推演协议（ljg-think）

```markdown
1. 锚定现象：剥离修辞，提炼核心物理命题。
2. 连续下潜（6 层下坠）：
   - 第一层（表面解释）：大众常识与公关说辞
   - 第二层（经济利益）：资金流向与交易成本
   - 第三层（博弈结构）：各方权力与非对称风险
   - 第四层（技术边界）：计算/物理/工程的客观硬约束
   - 第五层（人性幽暗）：安全感、虚荣心、控制欲与演化本能
   - 第六层（原点锚定）：不可再分的单一本质
3. 产出：以一句穿透力极强的断言封顶。
```

### 2. 降秩检验操作卡（ljg-rank）

```
[原始复杂系统 (数十个指标与现象)]
             ↓
[寻找冗余与伪因果] -> 哪些现象只是同一根力的不同投影？
             ↓
[提炼极少独立生成器 (通常只有 2~3 根)]
             ↓
[★ 逆向生长检验 (Generative Test) ★]
 ├── 生成器 A + 生成器 B 能否推导出现象 1？ (PASS)
 ├── 生成器 A + 生成器 C 能否推导出现象 2？ (PASS)
 └── 是否存在未被覆盖的残差？ -> 动态调整生成器
```

## 四、管家系统落地与实战转化建议

1. **用于战略决策与架构分歧裁决**：
   - 当主人面对复杂的系统架构选型或业务抉择纠结不下时，启动 `ljg-think-rank` 模式，将十几个伪顾虑降秩为 2 个根本约束；
2. **配合 ponytail（最懒架构师）**：
   - 先用 `ljg-think-rank` 看透问题的唯一本质，再用 `ponytail` 给出动刀最小的极简工程解法。
