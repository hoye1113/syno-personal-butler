        |              |              |
        |         ┌────┴────┐         |
        |         |         |         |
        |       FDE       6 能力      |
        |      (蜂群)    (好奇心)     |
        |              |              |
        └──────────────┼──────────────┘
                       |
                  自我认知/自信
                 (卡兹克/莫失莫忘)
                       |
                  落 地：人

**4 视角**：
- **趋势**（卡颂 / 极客）：蜂群组织 + 智能通缩

- **产品观**（三元）：品味与封装是护城河
