```

        ┌──────────────┼──────────────┐

        |              |              |
        |         ┌────┴────┐         |
        |         |         |         |
        |       FDE       6 能力      |

        |              |              |
        └──────────────┼──────────────┘
                       |
                  自我认知/自信
                 (卡兹克/莫失莫忘)
                       |
                  落 地：人
```

**4 视角**：
- **趋势**（卡颂 / 极客）：蜂群组织 + 智能通缩
- **岗位**（佳芮 / 柯芃丞）：FDE 模式 + 6 项能力
- **产品观**（三元）：品味与封装是护城河

**1 落地**：哲学/自我认知（莫失莫忘 3 答）—— 不管 AI 怎么变，最终都是"个人"在应对，自信是底层基建。
