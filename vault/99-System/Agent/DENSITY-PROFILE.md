# Vault 信息密度、中文写作画像与 Agent 契约规范 v4

> **理论基石**：参见 [[ljg-writes - 汪曾祺与阿城笔调纯正中文写作引擎]]、[[writing-for-agents - 高确定性高密度 Agent 契约指令写作法]] 与 [[AI 产品上下文压缩方法论与三板斧实践]]。  
> **核心原则**：**密度不是长度，语言拒绝塑料味，契约拒绝流程官僚，上下文依靠文件系统外挂大脑。**

---

## 一、 信息密度核心四要素（Density Framework）

每一篇存入知识库的笔记，必须至少保住一个明确命题，并有机制、证据或案例支撑。长度只用于发现异常压缩，不作为主要验收指标。

| 核心层级 | 必须保留的内容 | 失败/劣化信号 |
|---|---|---|
| **主张 (Claim)** | 作者在特定边界下做出了什么明确判断 | 只写讨论的主题，不敢给出断言 |
| **机制 (Mechanism)** | 为什么成立？底层因果链路与状态机怎样运转 | 只给干瘪的空洞结论，无推导过程 |
| **证据 (Evidence)** | 真实数字、代码案例、现场 Demo、不可替代的原话 | 用大而化之的抽象总结替代第一手事实 |
| **张力 (Tension)** | 生效边界、反例、极端限制、反对意见与争议 | 把特定场景的有限判断伪装成普适真理 |

## 二、 纯正中文写作画像（去 AI 塑料味五刀三磨）

全面融合李继刚汪曾祺/阿城笔调：**平视生活、短句白描、动词当先、骨力内敛**。

### 1. 彻底斩断 AI 翻译腔五大刀法
- 🪓 **第一刀：斩断套话转折** — 严禁出现“毫无疑问”、“值得注意的是”、“某种程度上”、“显而易见”、“总而言之”。
- 🪓 **第二刀：剔除弱势动词** — 严禁出现“进行讨论”、“做出决定”、“提供支持”；直接写“讨论”、“拍板”、“撑住”。
- 🪓 **第三刀：切断连词粘连** — 少用“此外”、“另外”、“不仅……而且……”；中文自有一气呵成的叙事脉络，顺着说即可。
- 🪓 **第四刀：抽象概念落盘** — 把“提高协同效率的解决方案”换成“两个人写同一份表不再打架”。
- 🪓 **第五刀：结构性大默念** — 默念每一句；凡是舌头打结、气口不顺的段落，整段推翻重写，绝不在烂句子上贴膏药。

## 三、 Agent 契约指令写作天梯（Writing for Agents）

编写任何 `SKILL.md`、`AGENTS.md` 或管家任务协议时，必须严格核算两项负荷并坚守信息天梯：

### 1. 两项负荷核算（The Two Loads）
- **上下文负荷 (Context Load)**：常驻系统窗口的每一行字都在持续稀释模型的注意力和 Token。只有全局硬规则才能常驻；其余一律使用精准的上下文指针（Context Pointer）按需加载。
- **认知负荷 (Cognitive Load)**：由人类判断并按需指派的成本。人类是最高索引；不要为了“省事”把所有文档全塞进模型常驻内存。

### 2. 信息天梯与渐进式披露（Information Ladder）
1. **梯级 1：文件内步骤 (In-file Step)** — Agent 每次必须按序执行的核心干线；
2. **梯级 2：文件内参考 (In-file Reference)** — 紧贴步骤放置的紧要规则与不变量（就近内聚原则 Co-location）；
3. **梯级 3：延迟披露参考 (Disclosed Reference)** — 外部详尽文档，仅在指针触发时按需调取，保护主干视野清爽。

### 3. 完成门限双防线（Completion Criteria）
- **清晰度 (Clarity)**：能够精确判定 Done vs Not Done，彻底消除“差不多改完了”的模糊表述；
- **要求度 (Demand)**：明确规定“逐一核对全部路径并执行自动化门禁验证”，坚决抵抗模型**过早草草完工（Premature Completion）**的心理惰性。

## 四、 上下文治理三板斧（Context Engineering）

内化 Manus 与 Claude Code 的顶级生产级上下文工程经验：

1. **缩减 (Reduce) — 压缩必须可恢复**：
   - 工具调用产生的冗长报错或中间探索结果，在进入下一阶段时进行结构化摘要，但**必须保留文件系统绝对路径与标识符**，随时可按需二次调取。
2. **卸载 (Offload) — 文件系统作为外挂大脑**：
   - 大文本、抓取网页原稿、命令日志优先写入本地沙箱或临时磁盘；模型只在上下文中持有文件路径与轻量状态，按需使用切片工具（`view_file` 指定行范围）读取。
3. **隔离 (Isolate) — 多 Agent 物理隔离噪音**：
   - 探索性查错、大规模文件扫描等高噪音任务，派发子 Agent 在独立沙箱中消化，仅将最终结果返回主会话。
4. **稳定前缀保护 KV Cache 命中率**：
   - 系统提示词与核心契约保持绝对静态，易变参数后置；工具接口定义固定不变，绝不破坏推理引擎的 KV Cache 命中。

## 六、 写作与收录自检清单

- 每章是否能用一句具体有力的短句概括？
- 抽象名词是否已经还原为具体人、动作与场景？
- 是否彻底清除了“毫无疑问”、“值得注意的是”等 AI 塑料词汇？
- 步骤完成门限是否可由测试和门禁脚本机械化核验？
- 历史工具产物是否已卸载至文件系统，主上下文是否保持清爽？
