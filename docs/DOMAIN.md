# Ubiquitous language

- **Note**：`vault/` 中可追溯、可关联的知识文件。
- **Artifact**：外部输入或执行结果，尚未成为长期知识。
- **ContentIdea**：可拍、可写但尚未展开的创作主张。
- **ContentBrief**：从知识与选题生成的制作说明。
- **Job**：一次有状态、可审计、可恢复的工作请求。
- **Action**：Job 对文件、日历或外部渠道产生的确定性操作。
- **PolicyDecision**：执行前固定的 Profile、执行级别、执行器和校验器。
- **MemoryProposal**：待受控执行的长期记忆候选。
- **ChannelMessage**：渠道无关的标准化入站/出站消息。
- **Event**：不可变的状态变化记录。

ClawBot 是微信里的独立 Bot 身份，不等同于扫码者的个人微信帐号。
