# Ubiquitous language

- **Note**：`vault/` 中可追溯、可关联的知识文件。
- **Artifact**：外部输入或执行结果，尚未成为长期知识。
- **ContentIdea**：可拍、可写但尚未展开的创作主张。
- **ContentBrief**：从知识与选题生成的制作说明。
- **Job**：一次有状态、可审计、可恢复的工作请求。
- **Action**：主人的待办行动，可记录排期、完成或归档；区别于系统后台 Job 和外部副作用。
- **PolicyDecision**：执行前固定的 Profile、执行级别、执行器和校验器。
- **MemoryProposal**：等待主人后续消息确认的个人记忆候选，仅在 `ops/memory/` 生效，不进入知识索引或发布。
- **IngestWorkflow / IngestProposal**：收录流程及其方案；接收、处理、待决策、本地保存与云端同步是不同状态。
- **PublishMap**：知识版本与 Wiki、图片、目录目标状态的持久映射；三端核验一致后才称同步完成。
- **ChannelMessage**：渠道无关的标准化入站/出站消息。
- **Event**：不可变的状态变化记录。

当前日常渠道为已绑定 Owner 的飞书私聊。微信、学习和项目子系统已删除；历史 ContentIdea／ContentBrief 等记录不代表旧工作台仍对用户开放。
