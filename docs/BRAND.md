# Syno 品牌与角色资产

## 角色方向

Syno / 赛诺是冷静、可靠、克制的私人管家。视觉语言采用沙漠审判者、胡狼守护意象、深靛紫、古金与暖米色，服务于“观察、整理、守护边界、推动行动”的产品人格。

用户给出的[赛诺百科页面](https://baike.baidu.com/item/%E8%B5%9B%E8%AF%BA/58677818)只作为高层角色气质参考。仓库不复制、不嵌入该页面的图片、游戏立绘、服装、武器、徽记或姿势。

## 使用原则

- 角色只在首页欢迎区、空状态和关键完成反馈中出现，不挤占知识阅读空间。
- 小尺寸使用时必须保持完整轮廓与足够对比度。
- 新变体应保持深靛紫、古金、暖米色与紫晶色，不直接模仿现有游戏角色造型。
