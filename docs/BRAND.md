# Syno 品牌与角色资产

## 角色方向

Syno / 赛诺是冷静、可靠、温暖的知识守护者。原创形象是一位人形埃及纸片法老管家：非动物神、无武器、无既有 IP 特征，不采用 3D、玩具或照片质感。纸莎草、卷轴、知识卡、星与羽毛表达“掌管知识、衡量证据、推动实践”。

## 视觉语言

- 暖纸莎草色工作区、深靛蓝导航、氧化旧金主强调色。
- 青金石蓝用于知识与链接，陶土色用于风险，纸莎草绿用于完成与健康状态。
- 角色资产使用背景、后景、主体、前景四层透明 PNG，保留白色纸边和轻微投影。
- 动画只表达等待、发现、提醒、完成和风险状态；`prefers-reduced-motion` 下使用静态帧。

## 使用原则

- 角色用于 Today 欢迎区、空状态和关键反馈，不挤占阅读空间。
- 小尺寸保持清晰轮廓、足够对比度和可替代文本。
- 不复制或嵌入第三方角色图片、服装、武器、徽记或姿势。
