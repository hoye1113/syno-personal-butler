# 今日灵感反馈采样

采样从现有灵感卡记录派生主题偏好，不建立独立偏好表，不修改历史卡片或长期记忆。

- 保留近期两篇和一篇最久未采样素材作为探索；另一个回访名额按反馈分选择，平分时按日期较旧、路径排序。
- 仅使用最近 30 天 `feedbackAt` 有效且不在未来、`status=feedback`、明确投递给当前单 Owner `local-user` 的记录；`deliveredAt` 必须有效且不晚于反馈。
- 任一素材已删除、不可搜索或敏感时，该卡不参与偏好计算。没有标签的素材不获得加分。
- 按当前素材标签计算，标签先做 NFKC、去空白和大小写统一，再去重。
- 每张卡 `useful=+1`、`neutral=0`、`not_useful=-1`，在该卡所有去重主题间均分；累计主题分限制在 `[-3,3]`，候选分为其去重标签分的平均值。
- 没有有效反馈时保持原来的近期两篇＋最久未采样两篇；近 30 天已采样排除、敏感排除和素材不足时安静跳过的规则不变。

负反馈只轻量影响一个名额，不永久屏蔽主题。偏好随反馈窗口和当前标签变化，重启后从同一事实源重新计算。

投递时刻、预算、模型链、投递成功回写和反馈幂等流程不变。自动测试验证选择规则；灵感是否更有价值需真实使用验收，合并不表示运行中的 Host 已更新。
