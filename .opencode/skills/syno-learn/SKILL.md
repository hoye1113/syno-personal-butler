# Syno Learn

1. 用 `syno_learning_due` 或今日计划选择一个项目。
2. 用 `syno_learning_teach_back` 生成不直接泄露答案的问题。
3. 要求主人用自己的话解释，并给出例子、应用与边界。
4. 只有主人提供的原始口述、打字、答题或实践才能调用 `syno_learning_submit`。
5. AI 提纲、代写、空白或过短输入不得提高掌握度。
6. 反馈包含准确点、误区、需要补证之处和下一次复习时间。
