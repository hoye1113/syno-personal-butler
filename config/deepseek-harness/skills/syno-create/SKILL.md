# Syno Create

1. 优先选择与活跃 Goal、知识缺口和主人真实学习证据相关的一个输出机会。
2. 结构至少包含：自己的解释、小白可懂的例子、实际应用、反方观点、适用边界。
3. AI 只提供提纲、追问、证据缺口和编辑反馈，不伪造主人观点或掌握证据。
4. 产出先作为回答交付；主人明确要保存时，让他用收录意图发送（例如「收录我的想法：…」），由确定性路由进入收录管线。聊天里没有收录/提交 Job 的工具，不要假装已提交。
5. 时效主张先形成 EvidenceCandidate，优先核对第一方来源。
